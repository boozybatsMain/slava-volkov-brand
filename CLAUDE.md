# Slava Volkov — сайт

Перед работой прочитать `HANDOFF.md`: там структура, принятые решения и что проверено.

Бренд (только то, что решил Слава) — `brand/README.md`. Маскот Нетопырь — `brand/mascot/`: 3D-просмотрщик и модуль для игр на three.js; сайт берёт его оттуда же.

- Две страницы: `index.html` и `games/index.html`, обе → `src/main.ts`. Игры — только в `src/games.data.ts`. Дизайн — финальный макет «Slava Volkov site, final page» (https://claude.ai/artifact/73QP7xhGixmhQ7zskNzdqS). Сверять с ним, не придумывать своё.
- Ручки арт-директинга — в `src/site.config.ts` (новые добавлять туда, с русским комментарием). Цвета обеих тем — токены в начале `src/styles.css`.
- Тексты в [квадратных скобках] — заглушки. Не заменять выдуманным, ждать текст от Славы.
- WebGL на сайте ровно один: маленький холст Нетопыря (`src/bat/`). Второй не заводить; рисовать только когда он виден.
- three.js закреплён на 0.170.0: под него настроен маскот (просмотрщик грузит ту же версию с CDN).
- Прежний сайт (небо, тайтл, ABOUT в 3D) лежит в `archive/v3-sky-site`, не в сборке.
- Скриншоты: `node scripts/shot.mjs --url <url> --out <png>`, все опции описаны в шапке файла.
- Свои Playwright-скрипты: браузер брать через `import { openBrowser } from '<repo>/scripts/shared-browser.mjs'` и `await openBrowser()` — это один общий headless Chrome на все запуски. Не вызывать `chromium.launch()` напрямую: каждый отдельный запуск Chrome стоит секунды и нагружает всю машину. Для замеров времени кадров — `openBrowser({ private: true })`.
- На 127.0.0.1:5173 часто работает dev-сервер другого проекта. Не убивать процессы по порту, не проверив их cwd.
