# Slava Volkov — hero

Перед работой прочитать `HANDOFF.md`: там структура, принятые решения и что проверено.

Бренд (только то, что решил Слава) — `brand/README.md`. Маскот Нетопырь — `brand/mascot/`: 3D-просмотрщик и модуль для игр на three.js.

- Все параметры арт-директинга задаются в `src/hero.config.ts`, это единственный источник правды. Новые ручки добавлять туда, с русским комментарием.
- Одна страница: `index.html` → `src/sky.ts` (версия 2, небо). Слои — `src/layers/*`, тайтл — `src/layers/title/raster` (по умолчанию) или `src/layers/title/mesh` (`title.mode: 'mesh'`: настоящие 3D-буквы, подогнанные к рендеру `scripts/title-mesh/fit.mjs`; HANDOFF, шаг 10). Версия 1 (бумага с окнами) лежит в `archive/v1-paper`, не в сборке.
- Тайтл намеренно низкого качества (дешёвый CGI конца 90-х). Не «улучшать»: никакого AA, сглаживания, апскейла.
- Скриншоты: `node scripts/shot.mjs --url <url> --out <png>`, все опции описаны в шапке файла.
- Свои Playwright-скрипты: браузер брать через `import { openBrowser } from '<repo>/scripts/shared-browser.mjs'` и `await openBrowser()` — это один общий headless Chrome на все запуски. Не вызывать `chromium.launch()` напрямую: каждый отдельный запуск Chrome стоит секунды и нагружает всю машину. Для замеров времени кадров — `openBrowser({ private: true })`.
- На 127.0.0.1:5173 часто работает dev-сервер другого проекта. Не убивать процессы по порту, не проверив их cwd.
