# NavDock

Вертикальная навигация-прогресс: тонкая линия, на ней точки разделов и подписи-флажки.

- Подписи — стиль `nav-dock`, прописные, цвет `nav-ink`; неактивные — прозрачность `nav-idle`, разделы без экрана — `nav-disabled` и не нажимаются.
- Текущий раздел — залитая точка; остальные — кольцо толщиной 1.5px. Линия 1px, пройденная часть плотнее.
- Позиция: справа сверху, отступ `dock-top`, шаг пунктов `dock-step` (телефон 44px), зона нажатия не меньше `hit`.
- Над чёрным бетоном навигация инвертирует то, что под ней (`mix-blend-mode: difference`) постоянной краской `nav-invert`: над пустотой это ровно `nav-ink`, над бетоном — светлый.
- На небе (первый экран) это горизонтальная полоска на плоскости имени (`nav`, `nav-sky`); при прокрутке она сматывается и встаёт вертикально.

Что даёт потребитель: список разделов (подпись, якорь, есть ли экран), текущий раздел. Исходник: `src/layers/sky-overlay/`.
