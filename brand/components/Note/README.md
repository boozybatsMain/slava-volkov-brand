# Note

Заметка — короткий текст от первого лица прямо в пространстве, без карточки и фона.

Четыре вида, по одному на роль:

- **note** — главная мысль кадра: стиль `note`, прописные, строки по 2–4 слова, цвет `ink`; под абзацем короткий прочерк (20px × 1px, через 14px).
- **list** — перечень (тема 02 на сайте): тот же стиль `note`, по пункту в строке.
- **aside** — рукописная ремарка: стиль `aside`, повёрнута на −6…−10°, прозрачность `aside-alpha`; одна на кадр.
- **count** — номер темы «01 / 05»: стиль `count`, цвет `ink-muted`; только для настоящей последовательности.

Что даёт потребитель: строки текста (переносы — вручную, по смыслу), вид, место в кадре. Заметки не накладываются на предметы, тени и навигацию ближе `clear` (16px). На пустоте — `ink`; на небе заметок нет.

Исходник на сайте: `src/layers/about-text/` (печатается строками ступеньками, см. «Движение и камера»).
