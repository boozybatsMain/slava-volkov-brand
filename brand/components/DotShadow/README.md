# DotShadow

Тень и появление в этом мире — только точки матрицы Байера 4×4: тень предмета на невидимом полу и проявление «сеткой».

- **Тень**: след предмета (проекция вдоль света сверху слева, вниз-вправо), размытый и нарезанный на 4 ступени плотности; каждая ступень — точки `shadow-dot`, максимум `shadow-density`. Чем выше предмет над полом — тем тень дальше, мельче и реже. Только на пустоте, только там, где нет предмета, только у видимого предмета.
- **Появление**: предмет проявляется пропуском пикселей по той же матрице — 0 → ¼ → ½ → ¾ → целое (`stipple-steps`), затем картинка на нём от грубой к чёткой.
- Пиксель — пиксель сетки рендера (`cell`), растянутый без сглаживания.

Чего не делать: заливку, blur, box-shadow, полупрозрачные пиксели. Исходники: `src/layers/slab/shadow.ts`, `src/layers/about/shaders.ts`.
