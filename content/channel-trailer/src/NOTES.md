# Трейлер канала — как собрано

Музыка: «Intergalactic» — Alex Jones / Xander Jones, фонотека YouTube (`../music/intergalactic.mp3`).
80 BPM, доля 0.75 с, такт 3 с, первая доля трека на 0.21 с.
Карта трека: тихое вступление до 12.21 → дроп 1 → … → провал 55.71–60.21 → дроп 2 на 60.21.

Склейка музыки: трек 7.71–33.225 + трек 54.195–66.24 (кроссфейд 30 мс по такту), фейд-аут 36.0–37.5.

| Трейлер | Музыка | Видео |
|---|---|---|
| 0–4.5 | вступление; подхват на 3.75 | остров / Sandstorm / взрыв дома — I BUILD / WHATEVER GAME / POPS INTO MY HEAD. |
| 4.5–19.5 | дроп 1, по такту на игру | Apex, снежок, Sandstorm, дракон, саванна + подписи |
| 19.5–25.5 | дроп 1 | быстрая нарезка: 4 × доля, 8 × полдоли (23/22 кадра) |
| 25.5–27.0 | склейка | Apex, занос с искрами |
| 27.0–31.5 | провал | снежок катится, колея (src 4.0–8.5) |
| 31.5–37.5 | дроп 2 | SLAVA VOLKOV + подписи, фейд |

Снежок: запись ~20 к/с, на 9–11 с подвисает, с 12.3 с разбивается — брать только 0–8.5 с.

Сборка (S — рабочая папка с подпапками shots/ и txt/):
```
python3 shots.py $S
uv run --with pillow python3 texts.py $S
ffmpeg -f concat -safe 0 -i $S/shots/list.txt -c copy $S/base.mkv
# music.wav — склейка трека, см. выше
python3 final.py $S trailer.mp4
```
